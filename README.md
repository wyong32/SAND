# SAND: Raiders of Sophie Guide

SAND: Raiders of Sophie Guide is an independent player reference for **SAND: Raiders of Sophie**, available at [sandraidersofsophie.com](https://sandraidersofsophie.com/).

The site is written for players who want practical help before and during a raid: how to prepare a Trampler, what weapons and ammunition are used for, which resources are worth tracking, how the tech tree affects planning, and how to think about routes across Sophie.

## About SAND: Raiders of Sophie

SAND: Raiders of Sophie is a PvPvE extraction game set on Sophie, a hostile desert world where players operate large walking machines called Tramplers. A run is not only about shooting or looting. It is about preparing a mobile base, choosing a route, managing risk, identifying useful resources, surviving pressure from other players or threats, and extracting before the cargo becomes too expensive to lose.

The game stands out because the Trampler is more than transportation. It is storage, protection, mobility, mounted firepower, and the center of a crew's plan. Good decisions often start before deployment: what to carry, what to upgrade, which route is realistic, and when to leave.

## What This Guide Covers

This guide focuses on player-useful information rather than broad marketing copy. It separates factual reference pages from tactical advice so players can quickly find the kind of answer they need.

- Item references for weapons, ammunition, and resources
- Beginner guidance for first stable runs
- Trampler tech tree planning
- Map and location guidance for route decisions
- Practical guides for survival, extraction, and raid discipline
- Searchable site content for faster lookups

## Guide Philosophy

SAND rewards players who can connect multiple decisions into one plan. This site is built around that idea.

A weapon detail is useful because it affects loadout planning. A resource entry is useful because it affects cargo value, crafting, or upgrade choices. A map note is useful because it changes where and when a crew should commit. A guide is useful when it helps players make better choices under pressure.

The goal is to help players answer practical questions:

- What should I prepare before a run?
- Which weapon or ammunition entry am I looking at?
- Is this resource worth saving?
- Which Trampler upgrades matter for my plan?
- How should I approach a route or extraction?
- When should I leave instead of chasing one more objective?

## Common Questions

### Is this an official SAND: Raiders of Sophie site?

No. SAND: Raiders of Sophie Guide is an independent fan-made reference. It is not affiliated with Hologryph, TowerHaus, tinyBuild, Steam, or the official SAND: Raiders of Sophie team.

### Where should new players start?

Start with [Getting Started](https://sandraidersofsophie.com/getting-started), then use the [Wiki](https://sandraidersofsophie.com/wiki) when you need item facts and the [Map & Locations](https://sandraidersofsophie.com/map-locations) page when planning routes.

### What is the difference between Wiki and Guides?

The Wiki is for reference data such as weapons, ammunition, and resources. Guides explain decisions: how to prepare, when to extract, how to reduce risk, and how to use reference data in a real run.

### Why does the site separate Weapons, Ammunition, and Resources?

Players often need different kinds of answers quickly. Weapons answer loadout and combat questions. Ammunition answers compatibility and damage-context questions. Resources answer cargo, crafting, trade, and progression questions.

### Does the site include a map?

The [Map & Locations](https://sandraidersofsophie.com/map-locations) page focuses on practical route and location guidance for Sophie. It is written for planning and field awareness rather than pretending every run can be solved by fixed coordinates.

### Can game values change?

Yes. SAND: Raiders of Sophie can change through updates. The site treats stats and item details as guide references, and important pages include dates or source-aware context where useful.
